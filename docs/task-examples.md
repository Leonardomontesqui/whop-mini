# Task examples — reference

Eight seed tasks across four categories. Used for demo seed data and as inspiration for what a "Whop bounty" can look like.

## Content

### Write a 5-tweet thread about Whop's creator economy
- **Payout:** $45
- **Deadline:** 2 days
- **Brief:** Punchy 5-tweet thread on why Whop hit $2.67B GMV. Hook in tweet 1, data in 2–4, CTA in 5. Deliver as a Google Doc.

### Edit a 60-second clip from a 20-min podcast
- **Payout:** $90
- **Deadline:** Tomorrow
- **Brief:** Pull the best moment, add captions, vertical 9:16. Final delivery MP4.

### Translate a 1,200-word product page to Spanish (LATAM)
- **Payout:** $80
- **Deadline:** 2 days
- **Brief:** Natural, conversational tone — not literal. Glossary provided. Return as a clean markdown file.

## Design

### Design 3 logo concepts for a Telegram trading group
- **Payout:** $180
- **Deadline:** 4 days
- **Brief:** Bold, crypto-native. Vector files (SVG + PNG). Reference: green/black palette, sharp edges.

## Dev

### Fix a broken webhook in a small Node script (Stripe → Discord)
- **Payout:** $120
- **Deadline:** 3 days
- **Brief:** ~50-line Node script that posts Stripe events to Discord. Stopped working last week. Fix + add a simple retry.

## Research

### Find 25 SaaS Discord communities for an outreach list
- **Payout:** $35
- **Deadline:** 5 days
- **Brief:** Name, invite link, member count, primary topic. Google Sheet output. No duplicates with existing list.

### Test new Whop onboarding flow and write up 5 specific bugs
- **Payout:** $60
- **Deadline:** 24 hours
- **Brief:** Web + mobile. 5 specific UX bugs with screenshots and reproduction steps.

## Social

### Post 1 IG Reel daily for a chocolate brand (7 days)
- **Payout:** $250
- **Deadline:** 1-week sprint
- **Brief:** Use provided footage. Trending audio. Vertical, 15–30s. Captions, 3 hashtags. Track views in a quick sheet.

---

## Notes on category choices

- **Content** — broadest bucket, easiest to relate to. Good "first bounty" examples.
- **Design** — higher payouts, makes the marketplace feel premium.
- **Dev** — even higher payouts, shows the range of work.
- **Research** — fits Whop's "find me information" vibe. Lower friction; common in real creator workflows.
- **Social** — recurring/sprint-shaped tasks (different from one-shot deliverables) show the model can handle campaigns, not just one-offs.
